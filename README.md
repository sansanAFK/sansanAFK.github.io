# 李智杰 · 视觉传达设计 — 数字作品集网站

把《作品集 ]_复制.pdf》这份 25 页横版幻灯片，做成了一个可以点击阅读的网站。
不依赖任何框架、不需要联网、不需要构建：双击 `index.html` 就能看。

---

## 一、怎么打开

**方式 A（最简单）**
双击 `index.html`，用 Chrome / Edge 打开即可。

**方式 B（本地起服务，推荐用于投屏演示）**
在本文件夹里打开终端，执行：

```
python -m http.server 8000
```

然后访问 `http://127.0.0.1:8000/`。

> 用方式 A 打开也没问题，代码里已经对本地文件协议做了兼容处理。

## 二、页面里有什么

| 区块 | 内容 | 交互 |
| --- | --- | --- |
| 首屏 `#top` | PORTFOLIO 大标题、蓝色手写署名、蓝色光标符号 | 自定义光标跟手；标题字母悬停微微上浮；底部跑马灯 |
| 目录 `#index` | 1#–4# 四个项目 | 悬停：该行整块被项目主色填满、文字反白；鼠标旁浮出一张预览图；点击进入项目 |
| 关于 `#about` | 自述、作品集原话引用、资料表 | 悬停色卡：整段背景被该颜色轻微浸染，同时读出色值 |
| 联系 `#contact` | 奶油色 END 页、电话/微信、本地时间 | 实时时钟；跑马灯；回到顶部 |
| 项目页（浮层） | 项目简介 → 幻灯片阅读 → 细节图 | 见下 |

### 项目页的三种状态

1. **简介**：进项目先看到项目名、英文名、设计说明、年份、幻灯片数量，右侧是主视觉大图。
2. **阅读**：整个 PDF 里属于该项目的每一页，按原顺序做成横版幻灯片。
   - `←` `→` 或 `空格` 翻页；左右两侧边缘也可以点。
   - 按住拖动 / 触屏左右滑动也能翻页。
   - `T` 打开或收起底部缩略图条，点缩略图直接跳页。
   - 点画面放大看原图（可继续左右翻）。
   - `全屏` 按钮进入全屏演示。
   - `Esc` 回到简介，再按一次退出项目。
3. **细节**：把该项目里最值得看的图单独排成一面墙，点任意一张放大。

地址栏会跟着变（`#/p/p1/s/4` 这种），所以可以直接把某一页的链接发给别人。

## 三、内容在哪里改

所有文字和图片对应关系都在 **`assets/js/data.js`** 一个文件里，不用碰 HTML。

```js
{
  id: 'p1',
  num: '1#',
  titleCn: '在山野 · 户外品牌提案设计',
  en: 'In the Mountains & Wilds — Outdoor Brand Proposal',
  cat: '品牌提案 / Brand Proposal',
  year: '2023',
  color: '#1d2088',          // 这一行悬停时填充的颜色
  desc: '……设计说明……',
  cover: 'assets/img/card-1.jpg',
  slides: [ { n: 3, cap: '引言 — 品牌提案设计' }, … ],   // n = 原 PDF 第几页
  gallery: [ { src: 'assets/img/xxx.jpg', cap: '说明' }, … ],
  palette: [ { name: '探湖蓝', en: 'Lake Blue', hex: '#1d2088', ink: '#fff' } ]
}
```

- **加一个项目**：复制一段对象，改 `id`（唯一）、`num`、文字；
  把图片丢进 `assets/img/`，把 PDF 页导出成 `assets/deck/s26.jpg` 这样的文件即可。
- **换幻灯片**：`slides` 里的 `n` 对应 `assets/deck/s03.jpg` 这样的文件名。
- **删项目**：删掉数组里那一项，目录会自动少一行。

## 四、图片是怎么来的

- `assets/deck/s01–s25.jpg`：原 PDF 25 页，按 1800px 宽导出（约 80% 质量），用于幻灯片阅读。
- `assets/img/*.jpg`：从原始页面里裁出的主视觉、标志、色彩、包装、物料等，用于封面、简介大图和「细节」墙。
- 需要重新导出时：`../tools/render_pdf.ps1`（把 PDF 渲染成 PNG）+
  `../tools/make_assets.py`（裁切压缩成网页图）。

原 PDF 的 25 页与项目的对应关系：

| 页 | 内容 |
| --- | --- |
| 1 | 封面 |
| 2 | 目录 |
| 3–9 | 1# 在山野 |
| 10–16 | 2# 浮山茶 |
| 17–24 | 3# 吉利 40 周年 |
| 25 | END |

> 4# 三宝灶在原 PDF 里只有目录条目、没有正文页，所以网站上保留了这个项目，
> 但内容标注为「整理中」。之后补图，只要把图片和 `slides` 填进 `data.js` 就会自动变成可阅读状态。

## 五、视觉规范（沿用 PDF 里的设定）

| 角色 | 色值 | 用在哪 |
| --- | --- | --- |
| 纸白 | `#ffffff` | 全站底色 |
| 墨黑 | `#0d0d0f` | 标题、正文 |
| 探湖蓝 | `#1d2088` | 强调色、手写署名、光标、进度条 |
| 奶油 | `#f9e9cd` | END / 联系页（取自 PDF 最后一页） |
| 郁葱绿 | `#006934` | 2# 项目色 |
| 吉利橙 | `#eb6100` | 3# 项目色 |

字体：标题用系统里最接近原 PDF 的无衬线粗体（Arial Black / Helvetica Neue），
正文与中文用系统黑体，手写注记用系统手写体（Windows 下是 Segoe Script）。
全部是系统字体，所以不联网也不会掉字。

## 六、放到线上

Vercel / Netlify / GitHub Pages / 任意虚拟主机即可，不用做任何额外配置。

## 七、几个小开关（做截图和调试用，日常不会碰到）

- `?shot=1`：关掉所有过渡动画，方便截图。
- `?view=index|about|contact`：把某个区块顶到页面最前面。
- `?hover=0`：模拟第一行目录被悬停。
- `?state=details`、`?state=thumbs`：配合 `#/p/p1` 直接打开项目的细节 / 缩略图状态。

去掉这些参数就是正常使用状态。
